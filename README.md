# Algorithm Learning

My personal algorithm practice repository, collected during my undergraduate and master studies.

It contains solutions to problems from LeetCode, AcWing and Luogu, written mainly in C++ and Python (a few in Java).

> I am not very strong at algorithms, so some solutions were assisted by AI and some of the better approaches did not come from me. I still learn a lot from them.

## Repository Structure

```
Algorithm/
├── Acwing/     # AcWing solutions (Algorithm, Programming)
├── LeetCode/   # LeetCode solutions, named <id>.<problem-slug>.<ext>
├── Luogu/      # Luogu problem sets, grouped by Question_sheet_1 ... Question_sheet_8
├── LICENSE
└── README.md
```

| Folder | Platform | Content |
| --- | --- | --- |
| `Acwing/` | [AcWing](https://www.acwing.com/) | Algorithm and programming exercises |
| `LeetCode/` | [LeetCode](https://leetcode.com/) | e.g. `1.two-sum.cpp`, `20.valid-parentheses.cpp` |
| `Luogu/` | [Luogu](https://www.luogu.com.cn/) | Problem sheets, files named by problem id such as `P1789.cpp` |

## Languages

- C++ (mainly)
- Python
- Java

## Usage

Compile and run a C++ solution:

```bash
g++ -std=c++17 -g P1789.cpp -o P1789
./P1789
```

Run a Python solution:

```bash
python3 P1554.py
```
